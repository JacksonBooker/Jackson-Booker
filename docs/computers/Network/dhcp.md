---
title: What is DHCP?
---

DHCP stands for Dynamic Host Configuration Protocol and manages IP addresses automatically. This information is coming from [Efficient IP](https://efficientip.com/glossary/what-is-dhcp-and-why-is-it-important/). 

There are four steps that are discussed in this video [DHCP Explained | Step by Step](https://www.youtube.com/watch?v=S43CFcpOZSI), which are DHCP Discover, DHCP Offer, DHCP Request, and DHCP Acknowlegement.
